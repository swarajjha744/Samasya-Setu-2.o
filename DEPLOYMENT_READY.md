## 🆘 If Something Goes Wrong

**Common Issues & Quick Fixes:**

### Issue: "Build Failed"
```
Check:
1. Run locally: npm run build
2. If it works locally, check Vercel logs
3. Look for TypeScript or dependency errors
4. Fix in GitHub, re-push, auto-redeploys
```

### Issue: "Page Shows Blank"
```
Check:
1. Is it still building? (Takes 2-3 min)
2. Check browser console (F12 → Console tab)
3. Try hard refresh: Ctrl+Shift+R
4. Wait 30 seconds and try again
```

### Issue: "Feature X Not Working"
```
Check:
1. Test on live site
2. Check browser console for errors
3. Try different browser
4. Try mobile vs desktop
5. Check if feature works locally
```
