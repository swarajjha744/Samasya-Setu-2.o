# 🚀 Deploy SamasyaSetu to Vercel (5 Minutes)

## Step-by-Step Deployment Guide

### **Step 1: Create Vercel Account**

1. Go to: https://vercel.com
2. Click **"Sign Up"** (top right)
3. Choose **"Continue with GitHub"**
4. Authorize Vercel to access your GitHub account
5. Done! Account created.

---

### **Step 2: Import Your Repository**

1. After signing in, you'll see Vercel dashboard
2. Click **"New Project"** (or "+ Add New" → "Project")
3. Click **"Import Git Repository"**
4. Search for: `Samasya-Setu-2.o`
5. Click **"Import"**

---

### **Step 3: Configure Project**

**Framework Preset:** React (auto-detected)  
**Root Directory:** `./` (default)  

**Build Command:** `npm run build`  
**Output Directory:** `dist`  

**Environment Variables:** (Leave empty for now)

---

### **Step 4: Deploy**

1. Click **"Deploy"**
2. Wait 2-3 minutes for build to complete
3. You'll see: **"Congratulations! Your project has been successfully deployed"**

---

### **Step 5: Get Your Live URL**

Your project is now live at a URL like:
```
https://samasya-setu-2-o.vercel.app
```

**Share this link everywhere:**
- ✅ Hackathon submission
- ✅ GitHub README
- ✅ LinkedIn
- ✅ Team members
- ✅ Judges/Mentors

## 🚨 Troubleshooting

**If deployment fails:**

1. **Check build locally first:**
   ```
   npm run build
   ```
   If this works locally, should work on Vercel.

2. **Check logs in Vercel:**
   - Go to Deployments → Latest → View logs
   - Look for error messages

3. **Common issues:**
   - Missing `.env` variables → Add to Vercel settings
   - Port conflicts → Usually auto-resolved on Vercel
   - Build failures → Check GitHub for recent changes
