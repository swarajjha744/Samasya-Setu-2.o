## 🎬 Video Editing Instructions (Using CapCut - Free)

### **Step-by-Step Editing Process:**

#### **1. Get Your Original Video**
```
- Download your YouTube video using:
  • 4K Video Downloader (free desktop app)
  • Or: youtube-dl command line tool
  • Or: savefrom.net (web-based)
```

#### **2. Open in CapCut**
```
- Go to: https://www.capcut.com (or download app)
- Create new project → Import your video
- Duration should be: 2:45 minutes max
```

#### **3. Replace/Record New Narration**
```
Option A: Record new voiceover
- Delete old audio track
- Add new audio → Record voiceover
- Read the script above with professional tone
- Use quiet room, decent microphone

Option B: Use AI voiceover
- Use ElevenLabs.io (free tier):
  * Paste script
  * Choose "professional" voice
  * Download MP3
- Import MP3 into CapCut
```

#### **4. Add Visual Elements**
```
- Add text overlays at key moments:
  * "500+ Problems Reported"
  * "24 Districts Covered"
  * "Real-time Tracking"
  * Feature names during demos

- Add transitions between sections (2-3 frames, not too flashy)
- Keep it professional, not overly animated
```

#### **5. Audio & Music**
```
- Use royalty-free background music:
  * YouTube Audio Library (best)
  * Epidemic Sound (free tier)
  * Incompetech.com
  
- Music should:
  * Start quiet under narration
  * Slightly louder in feature demos
  * Build during impact section
  * End strong at closing

- Audio levels:
  * Narration: 70-75%
  * Background music: 20-30%
  * Mix them so narration is always clear
```

#### **6. Color Grading (Optional but Professional)**
```
- Adjust video brightness/contrast slightly
- Match your brand colors (#0052a5 blue theme)
- Apply subtle color correction if video looks flat
```

#### **7. Export Settings**
```
- Resolution: 1920 x 1080 (Full HD)
- Format: MP4
- Bitrate: High quality
- Frame rate: 30fps
- Codec: H.264
```

## 📱 Critical Do's and Don'ts

### **DO:**
✅ **Show the actual website** - Real demos are powerful  
✅ **Slow down during feature demos** - Give time to understand  
✅ **Use clear, confident narration** - Professional tone matters  
✅ **Add text overlays** - Reinforce key points  
✅ **Show real impact** - Problems that got solved  
✅ **Keep it under 3 minutes** - Hackathon judges have limited time  
✅ **Use high-quality audio** - Bad audio kills professional look  
✅ **End with CTA** - Website URL or call to action  

### **DON'T:**
❌ **Shaky video** - Use stabilization in CapCut if needed  
❌ **Inconsistent volume** - Normalize audio levels  
❌ **Too many effects** - Keep it professional, not flashy  
❌ **Unclear narration** - Speak clearly and confidently  
❌ **Rambling explanation** - Stick to the script timing  
❌ **Too fast pacing** - Give time for comprehension  
❌ **Outdated or low-quality screenshots** - Use latest version  
❌ **Unclear call-to-action** - Make it obvious what to do next
